## 🧊 GRiTS Data Cube

Local tools for downloading, organizing, and reading gridded Earth observation data.

| Repository | Focus |
|:-----------|:------|
| 🛰️ [S1-GRiTS](https://github.com/ottoKae/S1-GRiTS) | Sentinel-1 SAR time-series data cubes |
| 🌈 [S2-GRiTS](https://github.com/ottoKae/S2-GRiTS) | Sentinel-2 native-resolution scene archives |
| 🌍 [LandSat-GRiTS](https://github.com/ottoKae/LandSat-GRiTS) | Landsat Collection 2 time-series archives |
| 🧠 [AEF-GRiTS](https://github.com/ottoKae/AEF-GRiTS) | Annual remote-sensing embeddings |
| 🔗 [GRiTS-Resolver](https://github.com/ottoKae/GRiTS-Resolver) | Windowed reading and alignment across GRiTS data cubes |
